สร้างค่าตั้งค่าบัญชีครู

ดาวน์โหลดไฟล์นี้แล้วเปิดด้วย Chrome บนเครื่องของครู การคำนวณทำในหน้านี้ ไม่มีการส่งรหัสผ่านหรือบันทึกลงไฟล์โดยอัตโนมัติ

นำค่าต่อไปนี้ไปใส่ใน Cloudflare → Worker → Settings → Variables and Secrets

เพิ่มเป็น Secret ทั้ง 3 รายการ โดยชื่ออยู่ด้านบนและ Value อยู่ในกรอบ

เก็บรหัสผ่านที่ตั้งไว้สำหรับเข้าสู่ระบบ ส่วนค่าที่แสดงในกรอบใช้ตั้งค่าเซิร์ฟเวอร์ อย่าอัปโหลดหน้านี้ที่กรอกค่าแล้วหรือคัดลอกค่าเหล่านี้ลง GitHub
