# SMART GRADE PRO TH 3.0 — Cloudflare

ระบบคะแนน ตารางสอน เช็กชื่อ รายงาน และรับรูปส่งงานสำหรับครูหนึ่งบัญชี ใช้ GitHub เก็บโค้ด, Cloudflare Workers รันเว็บและ API, D1 เก็บข้อมูล และ Google Drive เก็บรูปในโฟลเดอร์เดิม

เริ่มจาก **START_HERE_TH.html** สำหรับติดตั้งผ่านหน้า GitHub/Cloudflare หรืออ่าน **docs/INSTALL_TH.md** สำหรับรายละเอียดและวิธีติดตั้งอัตโนมัติผ่านเครื่องครู

หลังติดตั้ง อ่าน **docs/USER_GUIDE_TH.md** สำหรับจัดวิชา/ห้อง เพิ่มตาราง เช็กชื่อ กรอกคะแนน และแจกลิงก์นักเรียน

## สิ่งที่มีในชุด

- หน้าเข้าสู่ระบบครู อีเมล/รหัสผ่าน คุกกี้ HttpOnly และการตรวจต้นทางคำขอ
- หลายรายวิชา หลายห้อง งานแยกชื่อและคะแนนเต็มแต่ละห้อง รักษารหัสอ้างอิงงานเดิม
- นำเข้ารายชื่อ Excel/CSV พร้อมดูตัวอย่าง ตรวจรหัสซ้ำและเลขศูนย์นำหน้า แก้ทะเบียนนักเรียนผ่านเว็บ
- ตารางสอนรายสัปดาห์และรายวัน เช็กชื่อ มา/ขาด/ลา/สาย คาบชดเชย งดสอน และสรุปเวลาเรียน
- คำนวณคะแนนถ่วงน้ำหนัก เกรด อันดับ กลุ่มเสี่ยง ร./มส. และรายงานพิมพ์/PDF/CSV
- ลิงก์ดูคะแนนเฉพาะวิชาและห้อง พร้อมวันหมดอายุ เปลี่ยนและยกเลิก
- ลิงก์ส่งงานหนึ่งลิงก์ต่อวิชาและห้อง นักเรียนเลือกชื่อ ยืนยัน แล้วแนบรูป 1–3 รูป
- แสดงรายชื่อล่วงหน้าก่อนวันเริ่มเรียน พร้อมแจ้งวันที่เริ่มส่งรูป
- ให้เต็มในการส่งครั้งแรกเมื่อยังไม่มีคะแนน รักษาคะแนนที่ครูเคยให้ รวมถึง 0
- รับ JPEG ที่ย่อจากเบราว์เซอร์ ถอดรหัสภาพและคำนวณ SHA-256/dHash บนเซิร์ฟเวอร์ แจ้งรูปซ้ำ/คล้ายให้ครูตรวจ
- ย้ายข้อมูล Google Sheets เดิมทั้งชุด พร้อมนำเข้าซ้ำอย่างปลอดภัย และดาวน์โหลดสำรอง JSON
- D1 บันทึกเฉพาะรายการที่เปลี่ยน ใช้ transaction และ revision ป้องกันข้อมูลทับกัน

## เริ่มทดลองในเครื่อง

ติดตั้ง Node.js LTS รุ่น 22.13 ขึ้นไป เปิด Terminal ในโฟลเดอร์ที่มี package.json แล้วรัน:

```sh
npm install
npm run setup
```

เลือก `local` ตั้งบัญชีครูบนเครื่อง แล้วรัน:

```sh
npm run dev
```

เปิด URL ที่แสดงใน Terminal ค่าใน `.dev.vars` ใช้เฉพาะเครื่องนี้และไม่รวมในชุดเผยแพร่

## ติดตั้งใน Cloudflare ด้วยตัวช่วย

```sh
npm install
npm run setup
```

เลือก `cloudflare` ตัวช่วยจะเปิดการเข้าสู่บัญชี Cloudflare สร้าง D1 ให้คัดลอก database_id เตรียมตาราง เผยแพร่ Worker และตั้ง Secrets ให้ ดูรายละเอียดใน docs/INSTALL_TH.md

## ตรวจโค้ดและทดสอบ

```sh
npm run check
npm test
npx wrangler deploy --dry-run
```

ผลตรวจและข้อจำกัดอยู่ใน docs/QA_TH.md มีการทดสอบด้วย Workerd/D1 ในเครื่อง และเบราว์เซอร์กับ SQLite/Drive จำลอง ยังไม่ได้เผยแพร่หรืออนุญาต Google OAuth ในบัญชีครูแทนผู้ใช้

## ขอบเขต

รองรับทะเบียนกลาง 400 คนต่อชุดข้อมูลเช่นระบบเดิม เหมาะสำหรับครูหนึ่งบัญชีและหลายอุปกรณ์ ลิงก์ห้องใช้การเลือกชื่อ ซึ่งยังไม่ใช่การยืนยันตัวตนนักเรียนด้วยบัญชีโรงเรียน ครูตรวจรูปและชื่อที่เขียนบนงานประกอบ การแจ้งภาพคล้ายไม่ใช่ข้อสรุปว่าทุจริต

รหัสลับอยู่ใน Cloudflare Secrets และ refresh token ของ Drive เข้ารหัสใน D1 ไม่รวมใน GitHub หรือไฟล์สำรองข้อมูล รูปยังใช้สิทธิ์ของโฟลเดอร์ Drive เดิม ครูควรตั้งโฟลเดอร์เป็น “จำกัด” และเลือกแชร์เพิ่มเติมเองเมื่อจำเป็น

แผน Free มีข้อจำกัด CPU โดยเฉพาะการตรวจรูปและรหัสผ่าน ไม่รับประกันว่าโควตาฟรีรองรับทุกขนาดภาพ อ่านหัวข้อค่าใช้จ่ายในคู่มือก่อนเปิดใช้กับทั้งห้อง ชุดนี้ไม่สมัครแผนชำระเงินให้อัตโนมัติ
